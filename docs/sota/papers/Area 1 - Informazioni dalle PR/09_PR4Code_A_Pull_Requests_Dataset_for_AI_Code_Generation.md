# PR4Code: A Pull Requests Dataset for AI Code Generation

- **Autori:** Benedetta Donato; Leonardo Mariani; Daniela Micucci; Oliviero Riganelli
- **Anno:** 2026
- **DOI:** [10.1109/ACCESS.2026.3713096](https://doi.org/10.1109/ACCESS.2026.3713096)
- **Link ufficiale:** https://doi.org/10.1109/ACCESS.2026.3713096
- **Nota accesso:** IEEE Access è una rivista open-access; il DOI ufficiale è il punto di accesso consigliato.

## Breve riassunto

Gli autori presentano PR4Code, un dataset pubblico costruito per studiare la generazione di codice a partire da pull request reali. Il dataset contiene 13.339 PR, associate a 46.334 commit e provenienti da 1.055 repository GitHub Java e Python, conservando titolo, body, metadati, storia dei commit, file modificati e diff cumulativi. Il paper tratta esplicitamente titolo e body della PR come descrizione in linguaggio naturale del task di sviluppo e osserva che l'intento di alto livello è catturato soprattutto a livello di PR, mentre i commit tendono a descrivere azioni più operative. PR4Code fornisce quindi una base sperimentale riproducibile per studiare il legame tra descrizione della PR e attività software effettivamente realizzata.
