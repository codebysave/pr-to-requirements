# Recovering Traceability Links between Requirements and Source Code Using the Configuration Management Log

- **Nota accesso:** Articolo free access su J-STAGE/IEICE.

## Breve riassunto

Il paper propone di utilizzare il configuration management log per recuperare collegamenti di traceability tra requisiti e codice sorgente. Gli autori sfruttano la storia delle modifiche del progetto per individuare relazioni che non sono necessariamente espresse in modo diretto nei singoli artefatti. L'approccio permette inoltre di distinguere elementi comuni da elementi specifici. Il messaggio principale è che la storia del repository può essere trattata come una fonte attiva di conoscenza per ricostruire relazioni tra requisiti e implementazione.
