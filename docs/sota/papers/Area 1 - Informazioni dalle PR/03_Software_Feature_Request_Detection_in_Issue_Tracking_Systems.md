## Breve riassunto

Gli autori affrontano il problema di riconoscere automaticamente le richieste di nuove funzionalità negli issue tracker. Distinguono tre tipi di informazione: request, clarification e solution proposal, mostrando che la vera richiesta funzionale può essere mescolata con chiarimenti e proposte tecniche. Lo studio considera 599 issue, 3.519 commenti e oltre 11.000 frasi, evidenziando anche che la classificazione diventa più difficile quando si passa dall'intero issue alla singola frase. Il contributo centrale è quindi la separazione tra il bisogno espresso dall'utente e le successive discussioni sulla possibile soluzione.
