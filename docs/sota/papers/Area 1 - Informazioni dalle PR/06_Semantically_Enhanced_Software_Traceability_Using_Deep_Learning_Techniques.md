## Breve riassunto

Il lavoro affronta la software traceability utilizzando tecniche di deep learning per rappresentare semanticamente gli artefatti software. L'obiettivo è recuperare collegamenti rilevanti anche quando due artefatti non condividono le stesse parole o espressioni. Gli autori mostrano quindi il valore di una rappresentazione semantica capace di andare oltre la semplice similarità lessicale. Questo principio è particolarmente utile quando si vogliono trovare requisiti, issue o altri artefatti concettualmente vicini pur essendo formulati con vocabolari differenti.
