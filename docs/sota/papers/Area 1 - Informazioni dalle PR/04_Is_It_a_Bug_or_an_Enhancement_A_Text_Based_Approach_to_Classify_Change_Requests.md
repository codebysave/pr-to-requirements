# Is It a Bug or an Enhancement? A Text-Based Approach to Classify Change Requests

- **Autori:** Giuliano Antoniol; Kamel Ayari; Massimiliano Di Penta; Foutse Khomh; Yann-Gaël Guéhéneuc
- **Anno:** 2008
- **DOI:** [10.1145/1463788.1463819](https://doi.org/10.1145/1463788.1463819)
- **Link ufficiale:** https://doi.org/10.1145/1463788.1463819
- **Nota accesso:** Nessuna copia open-access verificata inserita nel pacchetto.

## Breve riassunto

Il paper propone un approccio testuale per distinguere automaticamente le change request che descrivono un bug da quelle che rappresentano un enhancement. Gli autori mostrano che il linguaggio contenuto nelle richieste di modifica possiede segnali sufficienti per aiutare questa classificazione. Il risultato è importante perché evidenzia che non tutte le modifiche software esprimono lo stesso tipo di intento: una richiesta può correggere un comportamento esistente oppure introdurre un miglioramento. Di conseguenza, il tipo di cambiamento deve essere considerato prima di interpretarlo come un nuovo requisito funzionale.
