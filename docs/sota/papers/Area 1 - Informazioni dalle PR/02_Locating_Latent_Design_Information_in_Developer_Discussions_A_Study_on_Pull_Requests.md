# Locating Latent Design Information in Developer Discussions: A Study on Pull Requests

- **Autori:** Giovanni Viviani; Michalis Famelis; Xin Xia; Calahan Janik-Jones; Gail C. Murphy
- **Anno:** 2021
- **DOI:** [10.1109/TSE.2019.2924006](https://doi.org/10.1109/TSE.2019.2924006)
- **Link ufficiale:** https://doi.org/10.1109/TSE.2019.2924006
- **Accesso open/preprint verificato:** https://michalis.famelis.info/wp-content/uploads/2019/06/tse19-draft.pdf
- **Nota accesso:** Draft/preprint ospitato sul sito di uno degli autori.

## Breve riassunto

Il lavoro studia quanta informazione di design rimanga nascosta nelle discussioni delle pull request. Gli autori analizzano 34 PR di Node.js, Rails e Rust, segmentandone le conversazioni in 10.790 paragrafi, e costruiscono classificatori per individuare quelli che contengono informazioni progettuali. I risultati indicano che una parte significativa della conoscenza di design viene discussa tra sviluppatori ma non trasferita nella documentazione ufficiale. La PR viene quindi proposta come una sorgente utile per recuperare conoscenza progettuale che altrimenti rischierebbe di andare persa.
