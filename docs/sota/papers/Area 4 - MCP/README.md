# Area 4 — MCP / Memoria persistente / Retrieval

Raccolta delle fonti utilizzate nello stato dell'arte **PR-to-Requirements** per motivare memoria storica, retrieval semantico e Model Context Protocol.

> **Distinzione fondamentale:** MCP non coincide con la memoria. Il database, il vector store e le politiche di persistenza sono componenti separati; MCP standardizza il modo in cui agenti e applicazioni accedono a dati e tool.

> Questa area contiene tre paper scientifici e una specifica tecnica ufficiale.

> Ogni scheda include metadati, link ufficiale, eventuale accesso open, breve riassunto e ruolo in PR-to-Requirements.

> I file non riproducono integralmente i paper o la specifica.
