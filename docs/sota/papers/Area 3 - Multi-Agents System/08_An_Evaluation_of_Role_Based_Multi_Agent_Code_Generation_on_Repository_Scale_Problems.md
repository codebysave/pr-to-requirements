# An Evaluation of Role-Based Multi-Agent Code Generation on Repository-Scale Problems

- **Autori:** Benedetta Donato; Noah Hagar-Dent; Aaron Worsnop; Leonardo Mariani; Valerio Terragni
- **Anno:** 2026
- **Venue:** IEEE Software
- **DOI:** [10.1109/MS.2026.3701516](https://doi.org/10.1109/MS.2026.3701516)
- **Link ufficiale:** https://doi.org/10.1109/MS.2026.3701516
- **Accesso open/preprint/repository:** https://arxiv.org/abs/2607.04212
- **Nota accesso:** Preprint open access su arXiv; articolo accettato su IEEE Software.

## Breve riassunto

Gli autori valutano la code generation multi-agente basata su ruoli su problemi a scala di repository. Il confronto viene condotto su 12 repository Java reali e mette a confronto approcci basati su singolo LLM e architetture multi-agent. I risultati indicano che i sistemi multi-agente possono produrre codice più simile a quello degli sviluppatori rispetto al singolo LLM, pur mantenendo un divario significativo rispetto alle implementazioni umane. Il lavoro evidenzia soprattutto l'importanza di confrontare le architetture agentiche con baseline controllate sullo stesso campione e usando metriche comuni.

## Uso nello stato dell'arte PR-to-Requirements

Il task procede nella direzione opposta a PR-to-Requirements, cioè requisiti/scenari → codice, ma il disegno sperimentale è direttamente trasferibile al confronto single-LLM vs multi-agent.
