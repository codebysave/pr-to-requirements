# Area 3 — Sistemi Multi-Agente / Generator–Critic

Raccolta dei lavori usati nello stato dell'arte **PR-to-Requirements** per motivare architetture multi-agent, pattern Generator–Critic, revisione iterativa, auto-correzione, memoria episodica e metodologia sperimentale.

> **Nota di classificazione:** Self-Refine e *Large Language Models Cannot Self-Correct Reasoning Yet* non sono sistemi multi-agente in senso stretto. Sono inclusi perché nello stato dell'arte vengono usati come baseline e contro-evidenza per valutare il valore di un critic separato.

> Ogni scheda contiene metadati, link ufficiale, eventuale accesso open/preprint, breve riassunto, ruolo in PR-to-Requirements e indicazione della base usata per il riassunto.

> I file non riproducono integralmente i paper.
